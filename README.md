# GIF Shqip

Galeri GIF-esh të animuara me CSS — kërko me tag-e shqip dhe ngarko të tutë.

## Veçori

- 12 "GIF-e" të animuara me CSS: zemër që rreh, top që kërcen, bare muzikore, balona, konfeti e më shumë
- Kërkim live me tag-e shqip (dashuri, qesh, sport, party…)
- Klikimi hap modal: preview i madh + tag-et + kod HTML embed
- Buton "Kopjo kodin HTML" — kopjon snippet-in embed në clipboard
- Buton "Ngarko GIF-in tënd" — ngarkon imazh nga pajisja (FileReader), shtohet në grid për sesionin
- Zero file GIF — gjithçka animacion CSS, 100% demo lokale
